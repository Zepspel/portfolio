# О проекте

Проект выполнен в рамках хакатона Nuclear IT Hack от НИЯУ МИФИ  по теме анализа Рамановских спектров в области ML и биомедицины.  
Срок выполнения задачи составил 28 часов, команда состояла из 4 человек.  
Дата проведения: 7.03.2026.

## Рамановские спектры

Рамановские спектры — это результат Рамановского рассеяния света: по сути, измеряется, как лазерное излучение взаимодействует с молекулами вещества.  
По форме и положению пиков в спектре можно судить о химическом составе и структуре образца, что делает метод удобным для биомедицинской диагностики.

## Постановка задачи

Команде был предоставлен набор рамановских спектров мозговой ткани, где каждый спектр — это зависимость интенсивности рассеянного света от волнового числа. 

Цель: разработать модель машинного обучения, которая по спектру определяет экспериментальную группу образца: 
- контрольная группа
- эндогенная экспрессия HSP70
- экзогенная экспрессия HSP70

Дополнительно требовалось: 
- выделить информативные спектральные области (пики), наиболее влияющие на различие между группами
- обеспечить воспроизводимый пайплайн предобработки, обучения и оценки модели в условиях ограниченного времени хакатона


# Ход работы

## Извлечение и подготовка данных

- Каждый `.txt` файл спарсили в pivot table (X, Y — индексы; Wave — колонки; Intensity — значения), сохранили в `.csv`
- Сформировали два датасета: `center=1500` и `center=2900`
- Незначительные расхождения wave (~0.1) внутри группы игнорировались — значения округлялись до 10-х

## Baseline и выявленная проблема

- Baseline XGBoost на `[intensities, brain_area, X, Y]` дал **1.0** по всем метрикам
- Причина: модель запоминала пространственные координаты X, Y — у каждого класса замеры шли в разных областях
- После удаления X, Y результат упал до **0.78**

## Feature Engineering

- Визуальный анализ спектров: классы различаются по max и mean интенсивности, форма пиков схожа
- Добавлены фичи по пиковым областям: интегралы, mean, max, std
- После добавления фич — hgboost дал **0.94**; самая важная фича — `region`
- Стандартизация и удаление baseline незначительно ухудшают метрики, но необходимы для корректности

## Результаты моделей

| Модель | F1-score | Примечание |
|---|---|---|
| **hgboost (center=1500)** | **лучший** | Финальная модель |
| hgboost (center=2900) | хороший | Финальная модель |
| CatBoost | ~0.87 | Сравнимо с hgboost |
| XGBoost | хуже | — |
| FNN | хуже hgboost | Не интерпретируема, не развёрнута |


# Инструкция по применению и назначения файлов

## Анализ данных и прочая информация

- graphics_1500 - построение графиков из агрегированной информации

- DOZEN_RESULTS.pdf - отчёт о проделанной работе

- columns_list_1500 - имя столбцов используемых моделями. (Для внутренего использования)

- columns_list_2900.txt - имя столбцов используемых моделями. (Для внутренего использования)

## Обработка данных

- txtToCsv - рекурсивно проходится по директории dataset отображая каждый .txt файл в файл .csv в директории datasetCsv.
Новые csv файлы содержат сводную таблицу по индексам X, Y, по колонкам Wave, по значениям Intensity

- mergeCsv - рекурсивно обходит директорию datasetCsv объяденяя все файлы в две таблицы, первая относится к center=1500,
вторая относится к center=2900

- featureEng_std2 - добавляет новые фичи, также нормирует и убирает тренд. Фичи представляют из себя:
- - агрегированные значения
- - интегралы по пиковым областям
- - производные по пиковым областям

## Обучение модели

- FNN - обучение и оценка нейронной сети, но в связи с результатами хуже чем у решающих деревьев, данная модель
не давелась до этапа развертования

- hgboost_2900 - обучение модели градиентного спуска на файле относящемся к center=2900

- hgboost_1500 - обучение модели градиентного спуска на файле относящемся к center=1500

- hgb_raman_pipeline_2900.joblib - обученная модель с помощью hgboost_2900

- hgb_raman_pipeline_1500.joblib - обученная модель с помощью hgboost_1500

## Использование модели

- probe - вспомогательный код, п озваляющий отсекать X, Y из dataset`а, необходимо для приведения
исходных данных к данным необходимым программе resultFirstTask

- resultFirstTask - развёртование модели и её применение. Требует особый формат данных.

### Касательно resultFirstTask

Программа ожидает следующее название файла:

{brain_region}_@_{group}_{wavelength}_center{center}_obj{obj}_power{power}_{time}_{acc}_map{map_size}_{step}_{place}.txt

Например название может быть следующим:

cortex_left_@_2Agroup_633nm_center1500_obj100_power100_1s_5acc_map35x15_step2_place1_1.txt

Формат данных должен быть представлен в виде 1015 строк. Например:
```
3288.140625	2344.016357
3287.397461	2556.801758
3286.654297	2451.644043
...
2460.666992	2774.618896
2459.766602	2762.930664
2458.866211	2698.284668
```

Тестовые данные для программы можно найти в этих файлах:

- - cerebellum_left_@_3group_633nm_center1500_obj100_power100_1s_5acc_map35x15_step2_place3_1.txt


- - cerebellum_left_@_3group_633nm_center2900_obj100_power100_1s_5acc_map35x15_step2_place1_3.txt
